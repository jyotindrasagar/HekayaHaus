## 5. Typography & Font System

The site utilizes a premium typography stack combining geometric grotesques, display headings, and ultra-legible body fonts:

1. **Syne** (`font-family: 'Syne', sans-serif`)
   - Role: Main Hero Titles, Large Editorial Headings, Statements
   - Character: High-fashion, avant-garde, luxury creative agency feel
2. **Satoshi** (`font-family: 'Satoshi', sans-serif`)
   - Role: Subheadings, Section Titles, Navigation Links
   - Character: Crisp, contemporary geometric sans
3. **Inter & Inter Display** (`font-family: 'Inter', sans-serif`)
   - Role: Paragraphs, Descriptions, FAQs, Form Inputs, Footer text
   - Character: High legibility, neutral, clean
4. **Bricolage Grotesque / Instrument Sans**
   - Role: Accents, Badges, Metrics & Numbers (e.g. `280%`, `95%`, `5K+`)
5. **Aldrich**
   - Role: Monospaced / Tech accents and tags

## 7. Grain & Glass Styling Formula

The signature Hekaya Haus luxury visual texture is created with:

```css
/* Signature Noise Overlay */
.noise-overlay {
  position: fixed;
  inset: 0;
  width: 100%;
  height: 100%;
  pointer-events: none;
  z-index: 999;
  opacity: 0.35;
  background-image: url('https://framerusercontent.com/images/rR6HYXBrMmX4cRpXfXUOvpvpB0.png');
  background-repeat: repeat;
  background-size: 256px 256px;
}

/* Glassmorphism Card Base */
.glass-card {
  background: rgba(23, 23, 23, 0.7);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 20px;
}

/* Glowing Pill Button */
.pill-button-gold {
  background: linear-gradient(135deg, #f3a80a 0%, #b27f1f 100%);
  color: #000000;
  font-weight: 600;
  border-radius: 9999px;
  padding: 12px 28px;
  transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1);
  box-shadow: 0 0 20px rgba(243, 168, 10, 0.3);
}
```
